🚀 Quick Setup

  1. Install Node.js 16+ on your system
  2. Clone this repository: git clone [repository-url]
  3. Navigate to project folder: cd webgis-playground
  4. Install dependencies: npm install
  5. Start the application: npm start
  6. Open http://localhost:3000 in your browser
  7. Allow camera access for gesture controls
  8. Follow the calibration process
Note: This is a complete React application with all components implemented. The project includes a fully functional 3D globe, hand gesture recognition, multiple map layers, and an intuitive user interface with modern design patterns.
