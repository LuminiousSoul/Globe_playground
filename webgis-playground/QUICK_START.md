# 🚀 Quick Start - WebGIS Playground

## 3 Simple Steps to Get Started

### 1️⃣ Install
```bash
npm install
```

### 2️⃣ Run
```bash
npm start
```

### 3️⃣ Allow Camera
Click "Allow" when browser asks for camera permission

---

## 🎮 Hand Gestures Cheat Sheet

```
✋ Open Palm       → Toggle Menu
👊 Fist            → Reset View
👉 Pointing        → Point Mode
✌️ Two Fingers     → Info Panel
👋 Swipe L/R/U/D   → Rotate Globe
🤏 Pinch           → Zoom In/Out
🖐️ Move Hand       → Continuous Rotation
```

---

## 🖱️ No Camera? Use Mouse!

- **Drag** = Rotate
- **Wheel** = Zoom
- **Click Menu** = Access features

---

## ⚡ That's It!

Your globe should now move with your hand gestures!

**Having issues?** Check `SETUP_INSTRUCTIONS.md` or `TEST_CHECKLIST.md`

---

**Pro Tip**: Keep your hand 1-2 feet from camera with good lighting for best results! 💡
